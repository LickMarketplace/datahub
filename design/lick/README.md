# Ressources graphiques LICK

Préparation esthétique uniquement, réalisée à partir de la présentation `LICK-2026_2027_dev-co.pptx`. Aucune modification des fonctions, du stockage, des scripts d'environnement ou des réglages publiés.

- `logo.png` : image originale extraite de `ppt/media/image5.png`, sans retouche ni déformation. Il s'agit du logo couleur présent dans la présentation ; le logo affiché dans le message comporte aussi une signature qui n'est pas présente dans cet élément extrait. Pour utiliser exactement cette version avec signature, fournir son fichier PNG/SVG séparé.
- `brand.css` : palette et composants de présentation, isolés avec le préfixe `lick-` pour préparer l'intégration sans affecter les autres éléments.
- `header.html` : aperçu graphique non fonctionnel de l'en-tête, des couleurs et des boutons.

Couleurs explicitement présentes dans les diapositives : #006C93, #00A6E2, #005978, #333F48, #F4F9FC et #C7DD39. Le turquoise #008C91 est une déclinaison visuelle du logo, pas une couleur certifiée par une charte formelle. Arial pour le texte ; Montserrat pour les titres si installée, sinon Arial. Aucun chargement de police distante.

Dans cet environnement, les fichiers de l'ancienne maquette ne sont pas présents : cette ressource n'est pas une restauration de l'interface. L'intégration à la maquette nécessite de récupérer ses sources ou son HTML autonome. Conserver les identifiants, la logique d'import, les versions, le stockage et les données utilisateur lors de cette intégration.
